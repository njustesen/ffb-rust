# BB2025 Parity Team Drafts

Hand-drafted 2026-08-08 under the official BB2025 drafting rules
(`rules/core_rules/04_drafting_a_blood_bowl_team.md`) with the project
heuristics: budget 1,100,000; all positionals incl. a Big Guy (respecting the
per-team shared Big-Guy limits: Chaos Chosen 1 — Minotaur chosen; Underworld 1
— Warpstone Troll chosen; Chaos Renegades 3 — Troll/Ogre/Minotaur chosen, Rat
Ogre dropped); 12+ players when affordable; 2+ team re-rolls; apothecary when
allowed and affordable after positionals; Dedicated Fans to 3 (5k each);
remainder treasury. Jerseys run premium positions first, so the first 11
jerseys start on the pitch and linemen sit in reserve.

The frozen teams live in `data/teams/bb2025/team_<race>.json` (one spec per
race; home/away parity teams are identical builds). TV per the Java
`UtilTeamValue` formula (Dedicated Fans excluded in BB2025).
