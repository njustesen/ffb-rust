The parity matrix compares Rust against stock Java step by step. It says whether they agree, not about what. This sheet reads the Rust event stream of the same 33,000 games and tallies what actually happened, then holds each tally against the engine's own catalogs to show what never came up.

The event stream is not the whole record. Both engines also keep the report list the game client renders, and that one carries the roll modifiers by name. A separate sample of 300 games captures it from both sides and compares them report by report — see Reports.
